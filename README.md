# 채비 chaebi

묘은흘림체 Light와 크림·말린 장미색 디자인의 준비물 체크 웹앱입니다.

## 기능

- 반복 없음 / 일간 / 주간 / 월간 / 선택 날짜 반복
- 여러 월과 연도에 걸친 날짜 선택
- 날짜별 체크 상태, 특정 날짜만 수정, 범위별 삭제
- 브라우저 자동 저장 및 JSON 내보내기

## GitHub Pages 배포

저장소의 Settings → Pages → Build and deployment에서 Deploy from a branch를 선택하고 main 브랜치의 /(root)를 저장합니다. 배포가 완료되면 Pages에 표시되는 주소로 접속합니다. 별도 빌드나 서버는 필요하지 않습니다.

## 개발과 검증

Node.js가 설치된 환경에서 `node test.mjs`로 반복 로직 테스트를 실행합니다. 로컬 실행은 `python3 -m http.server 3000` 후 http://localhost:3000 으로 접속합니다.

## 데이터 저장

준비물은 접속한 주소와 브라우저의 localStorage에 저장됩니다. 기기 간 동기화는 지원하지 않습니다. 기존 ChatGPT Site의 데이터는 GitHub Pages 주소로 자동 이전되지 않습니다. 기존 앱에서 기록을 내보내 보관하세요. 이 버전에는 가져오기 기능이 없습니다.

## 폰트

사용자가 제공한 그리운 묘은흘림체 Light 원본 파일을 사용합니다. 폰트 권리는 제작자에게 있으며 별도 사용 조건을 따릅니다. 폰트 파일을 수정하거나 판매하지 마세요.
